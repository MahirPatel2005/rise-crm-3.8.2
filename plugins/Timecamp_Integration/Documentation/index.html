Timecamp Integration
plugin for
RISE CRM

It's a plugin for RISE CRM which will sync your projects and tasks with Timecamp.

Installation
  • Please login as Admin in your RISE app.
  • Go to the Settings > Plugins page.
  • Install the Timecamp-Integration-for-RISE-CRM.zip which you have downloaded from the codecanyon.
    It'll require the item purchase code. Don't use any nulled version for your security.
  • If everything is OK, you'll get a success message after installation.
  • Activate the plugin from the option dropdown of the plugins list.
  • Go to Settings > Setup > Timecamp Integration.
  • Collect the API token from your Timecamp account and save in the settings.
    Also you can select all/specific projects to sync to Timecamp from there.
  • There will be a Sync button available after saving the setting. You can push all projects and task to Timecamp instantly by pressing that button.
  • After that, any add/changes with project/task, will effect in Timecamp instantly.

Upgrading Guide

There is a easy way to update the plugin.

To install any updates, please go to Settings > Plugins > Timecamp Integration > Dropdown > Updates. The download will be started automatically if there is any new update available. Once the download is complete you can install the updates by clicking on the link.

Please backup all files and database before starting the installation of new updates.
